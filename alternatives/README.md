# Portfolio alternatives

Two independent directions for Rahul Hira’s personal website.

- **Painted Garden**: a 3D landscape using the brushwork from Rahul’s Intelligence Age essay, with clickable flowers, stones, and a water lily.
- **After Hours**: a minimal personal page in white type, with Moonlight, Tide, and Ember atmospheres.

Private previews (ChatGPT sign-in):

- https://rahul-hira-painted-garden-20261115.rahulhira.chatgpt.site
- https://rahul-hira-after-hours-20261115.rahulhira.chatgpt.site

Each directory has a complete static site in `dist/` and local serving instructions. These prototypes do not change the public homepage or domain configuration. The original room prototype is available separately on the `codex/room-portfolio` branch.
